# 示例论文来源

首页提供以下论文及作者仓库入口。导入时，论文 PDF 和体验指引保存到当前用户的项目中。

| 示例 | 论文与作者 | 原始 PDF | 作者代码 |
|---|---|---|---|
| GCN | Thomas N. Kipf、Max Welling，Semi-Supervised Classification with Graph Convolutional Networks，ICLR 2017 | https://arxiv.org/pdf/1609.02907 | https://github.com/tkipf/gcn |
| SGC | Felix Wu 等，Simplifying Graph Convolutional Networks，ICML 2019 | https://proceedings.mlr.press/v97/wu19e/wu19e.pdf | https://github.com/Tiiiger/SGC |

论文保留原始内容及作者署名，论文版权与作者代码的许可分别适用。GCN 代码的 MIT 许可见作者仓库 LICENCE，SGC 代码的 MIT 许可见作者仓库 LICENSE。数据按作者说明获取，不包含在示例目录中。

建议从 CPU 上的 Cora 节点分类开始。导入不会启动训练，进入项目后可以先向助手了解论文和参数，再准备并确认实验。

如果想要运行与 GPU 相关的实验，强烈推荐本地部署。
