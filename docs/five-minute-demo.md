# 五分钟项目演示

## 提前准备

1. 为演示的不同阶段准备不同项目，例如材料上传、待批准方案、训练完成和结果报告。各项目正常使用作者开源仓库或上传的作者源码。
2. 在“项目总览”中，对每个项目分别点击“新页面打开”。也可以从侧栏项目菜单打开新页面。每页都是完整、可操作的项目工作台。
3. 需要新项目时，点击“新页面新建项目”。项目页的“另开项目页面”会在新标签页打开项目列表，当前项目保留。
4. 比赛前，在各页分别完成耗时准备，并选择需要展示的实验记录。现场切换浏览器标签页，展示各项目已经到达的真实阶段。

每个工作台使用 URL 中的项目编号；实验选择也保存在该页的 URL 中。不同项目的证据、实验记录和操作互相隔离，标签标题显示项目名称和编号。切换同一标签页的项目时会重新建立界面状态，不沿用上一个项目的复现目标、源码地址或对话草稿。

同一个项目在两页打开时仍共用该项目的真实记录。若要隔离操作，应创建不同项目。多模型调度是账号级配置，各项目页仍可单独选择本次复现和对话使用的模型。

## 现场顺序

| 页面 | 展示内容 | 建议时间 |
|---|---|---:|
| 论文与实验目标 | 上传材料、运行目标、提取的实验规范 | 40秒 |
| 源码、环境与数据 | 作者来源、环境命令、数据准备及实际时间记录 | 60秒 |
| 执行命令与训练日志 | 批准的命令和实际输出 | 50秒 |
| 代码修改与校验 | 已保存的需求、代码差异、验收条件及Agent协作记录 | 70秒 |
| 结果、曲线与报告 | 真实采样点、论文目标、基线、调参与报告 | 80秒 |

工作台保留上传、协作、修改和实验操作。现场跳过等待依靠提前准备，不伪造进度。启动训练或安装环境仍按正常流程独立确认。

此前的 `/projects/:id/demo` 链接保留为历史记录只读浏览入口，不作为多项目独立操作的入口。

## 环境和下载速度

- 环境复用：同一项目优先使用已经准备好的独立环境。后续修改和重跑保留原环境与记录。
- 终端输出：ReproMind 子进程关闭 Conda 公告查询、更新提示和动态进度动画，减少无关网络请求。网页和助手清理退格及ANSI控制符，磁盘原始日志保留。
- 本机代理：pip明确报告本机代理连接失败时，仅对原已批准软件源做一次直连重试。保持TLS验证，保存失败和重试日志，不改变系统代理或全局pip配置。同一运行后续安装步骤沿用已成功的直连方式。
- 分段下载：2—256MiB且支持字节范围、提供稳定文件版本标识的文件，默认使用4个并行连接。范围、版本、总长度以及已有校验和检查全部保留。暂停后保留分段；不满足条件时使用原有流式下载。
- `DATASET_DOWNLOAD_WORKERS` 可设为1—8，设为1关闭分段并行。`PIP_INDEX_URL` 仍可显式配置可信HTTPS索引。作者固定版本和数据来源不会为加速而自动替换。

环境首次准备和数据首次获取仍应在比赛前完成。现场展示结果页面即可跳过等待，不需要缩减训练、伪造进度或覆盖旧实验。
